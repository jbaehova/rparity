### 2단계 기준 관찰과 진단 체크포인트

GAM 1,200건과 TMB 1,200건의 합성 설계를 R 오라클로 관찰했다. 최종 입력 기준
R 실행 오류는 없다. 원래 Beta 끝점 오류 2건과 TMB 최적화 설정 변경 전 관찰값은
각 사례에 보존했다. 아직 전체 수치 통과율을 확정하지 않았다.

필수 GAM 기저 35건과 수치 진단 30건의 로컬 검증을 완료했다. GAM 평활항 추론과
TP 좌표 정렬, TMB 복잡한 분산 모형의 최적화 개선을 병렬 진행한다. 루트는
TMB 사후 분석 연결과 새 데이터 예측, 단계별 검증 기록을 통합한다.

### 2단계 런타임과 통합 체크포인트

GAM 네 분포족과 세 선택법, TMB 여섯 분포족과 실제 observed-Hessian Laplace
적합을 구현했다. 로컬 단위 및 공개 API 검사 244건이 통과했다. TMB의 추가
랜덤효과 불확실성 보정 이후 단위 및 통합 검사 42건도 통과했다. mypy는
소스 27개 파일에서 문제가 없었다. 마이그레이션 문서의 strict 빌드가 통과했다.

TMB 기준값은 1,200건 모두에 동일한 공개 optimizer callback으로 score를
보강했다. 독립적으로 R에서 확인한 더 좋은 시작값 14건과 GAM 시작값 2건은
oracle/stage2_overrides.json에 기록했다. 원래 입력과 결과는 모두 보존했다.
TMB 경계 해 39건은 개별 확률, 우도 영향과 곡률 검사 후 기존의 식별 가능한
수치와 출력 레이아웃 검사를 통과했다. 전체 통과율은 아직 확정하지 않았다.

GAM 최신 전체 검사는 886건 통과와 314건 실패다. 이 기록은 CS 수치 backend
개선 전의 중간 결과다. 남은 기저, 경계 해와 최적화 metadata 차이를 조사한다.
완료 기준을 만족하기 전에는 v0.2.0 태그나 Release를 만들지 않는다.

1단계 전체 회귀 검사를 로컬에서 다시 완료했다. 골든 3,856건 중 3,799건 통과와
기존 실패 57건으로 기준과 동일하다. 일반 테스트 119건과 R 예제 14건 모두
통과했고 pytest는 3,931 passed, 57 xfailed, 1 xpassed를 기록했다. 신규 실패나
skip은 없다. 이 결과는 최종 전체 검사에서 다시 확인한다.

### 2단계 수치 경계와 배포 backend 체크포인트

GAM 최신 전체 검사에서 골든 1,200건 중 1,147건이 통과하고 53건이 실패했다.
이전 중간 결과의 실패 314건에서 줄었지만 아직 완료 기준에 미달한다. 원본 관찰과
모든 실패 건을 보존한다. 20건의 독립 R 재최적화 및 정밀도 보정 참조를 반영했다.

개별 GAM 경계 6건과 positive-penalty limit 137건, joint-gauge limit 7건에
수학적 검증을 추가했다. 식별 가능한 수치에는 기존 허용오차를 유지한다. 변조 입력
거부 검사 13건과 런타임 및 통합 검사 352건이 로컬에서 통과했다. Ruff와 mypy도
통과했다. TMB 공분산 경계와 남은 내부 해 정밀도 검증을 계속 진행한다.

CS 기저의 작은 고윳값을 보존하는 OpenBLAS backend를 wheel 빌드에서 포함하도록
구현했다. R 없는 깨끗한 macOS ARM64 환경에서 wheel 및 editable 실행을 확인했다.
다른 플랫폼 실행은 아직 검증하지 않았다. 현재 버전은 0.1.0이며 2단계 기준을
충족하기 전에는 0.2.0 태그나 Release를 만들지 않는다.

### 2단계 독립 참조와 최종 수치 검사 체크포인트

GAM 전체 골든 1,200건 중 1,184건 통과, 16건 실패를 로컬에서 확인했다.
직접 R 재최적화와 정밀도 보정 참조 52건을 추가 검증했으며 모든 원본 관찰을
각 fixture에 보존했다. 일반 GAM numerical-limit 정책은 145건이고 joint-gauge
정책 7건과 Gaussian 경계 정책 6건도 각각 실행 가능한 수학적 guard를 유지한다.

TMB 전체 1,200건의 이전 검사에서 55건이 실패했다. 이후 20건의 더 건강한
참조와 7건의 안정된 분산 및 Hessian 참조를 반영했다. 상관 경계 보조 참조는
12건이며 원본 AIC/BIC의 명목 모수 수를 유지한다. 현재 전체 TMB 수치 검사를
다시 실행 중이라 최종 통과율은 아직 확정하지 않는다.

중복 x값이 있는 CR/CS knot 계산을 고유값 분위수로 수정했다. native-support
penalty root가 블록 간 반올림 누출을 줄이고, 정확한 상관 경계의 TMB 정보행렬은
Richardson 보정으로 유한차분 오차를 줄인다. 대표 R 예제 2건, 런타임 49건과
새 수학 guard 20건이 통과했다. 이전 R 예제 14건과 합친 최종 검증을 앞두고 있다.
문서 strict 빌드와 예제 실행도 로컬에서 확인했다. 완료 게이트 통과 전에는
v0.2.0 버전 및 태그를 확정하지 않는다.

### 2단계 원본 전체 비교 게이트

최종 raw 비교에서 GAM 1,184/1,200건, TMB 1,172/1,200건이 통과했다.

이 수치는 합계 98% 기준을 충족한다. 실패를 삭제하거나 통과로 집계하지 않는다.

대표 모형 5개를 같은 머신에서 직렬 측정했다. Ruff와 mypy가 통과했다.
버전 metadata를 0.2.0으로 준비했으며, 최종 전체 회귀 검사와 깨끗한 wheel
설치 검증을 수행한다. 문서는 v2-fan 작업자가 마무리한다. 태그 및 Release는
이 검증이 완료된 뒤 생성하고 3단계와 PyPI 업로드는 진행하지 않는다.

## 사용자용 라이브러리 구성 정리

사용자가 현재 기능 범위에서 개발을 마무리하며 단계 완료와 버전 중심의
소개를 제거하도록 요청했다. README와 문서 첫 화면은 설치, Python 사용과
분석별 가이드를 중심으로 바꾼다. 공개 API를 쓰는 독립 실행 예제 4개를
examples/에 추가했다. 오라클과 보고서, 개발 기록은 development/로 옮겼다.
릴리스 식별에 필요한 패키지 버전 및 과거 검증 기록은 보존한다.

검색을 위한 페이지별 제목과 설명, canonical 주소와 sitemap을 설정했다.
현재 제공하지 않는 메타분석은 프로젝트 소개에서 제거했다. 이미지 생성은
하지 않는다. 실행 예제와 새 경로, 전체 로컬 검증을 확인한 후 게시한다.

README와 문서의 설치, quickstart, 분석 가이드와 API reference를 완성했다.
독립 Python 3.11 환경에 새 wheel을 설치하고 공개 API 예제 4개를 실행했다.
R과 rpy2가 없는 환경에서 실행됐으며 외부 프로세스 호출은 없었다.
문서 코드 16개도 로컬에서 실행했다. macOS ARM64 외 플랫폼은 검증하지 않았다.

경로 정리 후 전체 로컬 pytest는 6,837 passed, 101 xfailed, 1 xpassed다.
새 실패와 skip은 없고 기존 골든 입력과 허용오차는 변경하지 않았다.
Ruff, mypy와 strict 문서 빌드가 통과했다. 최신 validation.json을 새 경로에
기록하고 커버리지 페이지를 재생성했다. 페이지 17개의 제목, 설명과 canonical
주소를 확인했다. GitHub 소개, 홈페이지와 검색 태그도 사용자 기능에 맞췄다.
버전 태그와 기존 릴리스 첨부물은 유지하며 이번 변경은 main과 문서에 반영한다.
